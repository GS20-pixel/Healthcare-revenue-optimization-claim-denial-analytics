## 📌 Project Overview

Healthcare organizations process thousands of insurance claims every day. Claim denials, delayed reimbursements, and revenue leakage can significantly impact financial performance.

This project analyzes a synthetic California hospital dataset (Q1 2025) to evaluate the complete Revenue Cycle Management (RCM) process. Using SQL, Python, and Power BI, the project identifies revenue leakage, analyzes claim denials, evaluates insurance performance, and provides actionable business insights to improve hospital revenue operations.

## 🎯 Business Problem

Hospitals often lose revenue because of:

- Insurance claim denials
- Delayed reimbursements
- Revenue leakage
- Inefficient appeal processes
- Operational inefficiencies

The objective of this project is to identify these issues through data analytics and provide insights that support better financial decision-making.
