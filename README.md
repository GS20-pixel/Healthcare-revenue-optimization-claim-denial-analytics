# 📌 Project Overview

Hospitals process thousands of insurance claims every day. Delayed reimbursements and claim denials can lead to revenue loss and impact financial performance.

This project analyzes the **CA Hospital Dataset (Q1 2025)** to understand the hospital revenue cycle, identify revenue leakage, evaluate insurance provider performance, and generate business insights using SQL, Python, and Power BI.

---

# 🎯 Business Problem

Hospitals often lose revenue because of:

- Insurance claim denials
- Delayed reimbursements
- Revenue leakage
- Inefficient appeal processes
- Operational inefficiencies

This project focuses on identifying these issues and providing insights to support better financial decision-making.

---

# 🎯 Project Objectives

- Analyze the complete hospital revenue cycle.
- Measure key financial KPIs.
- Identify the main causes of claim denials.
- Compare insurance provider performance.
- Evaluate provider and department performance.
- Build an interactive Power BI dashboard.
