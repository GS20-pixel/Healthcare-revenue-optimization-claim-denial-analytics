# Healthcare Revenue Optimization & Claim Denial Analytics

## Project Overview

This project focuses on analyzing healthcare revenue and insurance claim performance using a hospital dataset. The objective is to identify revenue leakage, understand claim denial patterns, and evaluate insurance provider performance through data analysis and interactive dashboards.

The project follows an end-to-end data analytics workflow, including data cleaning, SQL analysis, Python-based exploratory data analysis (EDA), and Power BI dashboard development.

---

## Problem Statement

Healthcare organizations process thousands of insurance claims every month. Delayed payments, denied claims, and revenue leakage can significantly impact financial performance.

This project aims to answer key business questions such as:

- What is the total billed and collected revenue?
- What is the overall claim collection rate?
- Which denial reasons contribute most to revenue loss?
- Which insurance providers generate the highest revenue?
- How do monthly revenue trends change over time?

---

**Source:** CA Hospital Dataset (Q1 2025)
